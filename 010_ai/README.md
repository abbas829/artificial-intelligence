# 📘 010 — NumPy (Part 1)

## 🎯 Learning Objectives
- Create and manipulate NumPy arrays
- Apply vectorized mathematical operations
- Understand broadcasting and indexing

## 📂 Files

| File | Description |
|------|-------------|
| `numpy.ipynb` | Core NumPy: arrays, operations, indexing, slicing, broadcasting |

## 🔑 Key Concepts
- `ndarray` creation: `np.array()`, `np.zeros()`, `np.ones()`, `np.arange()`, `np.linspace()`
- Array attributes: `shape`, `dtype`, `ndim`
- Mathematical operations: add, subtract, multiply, divide
- Broadcasting rules
- Indexing and slicing (1D, 2D, nD)
- Aggregation: `sum`, `mean`, `std`, `min`, `max`
