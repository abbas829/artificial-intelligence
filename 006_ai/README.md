# 📘 006 — File Handling & I/O

## 🎯 Learning Objectives
- Read and write files in various formats (text, CSV, JSON)
- Understand Python's context manager (`with` statement)
- Manage experiment configs, logs, and model outputs programmatically

## 📂 Files

| File | Description |
|------|-------------|
| `file_handling.ipynb` | Complete guide to Python file I/O: reading/writing text, CSV, JSON, and binary files |
| `best_model.json` | Example JSON output storing best model configuration |
| `clean_data.csv` | Sample cleaned dataset |
| `messy_data.csv` | Sample raw/messy dataset for cleaning demonstrations |
| `dataset_info.json` | Dataset metadata in JSON format |
| `experiment_config.json` | ML experiment configuration file |
| `fast_models.csv` | CSV listing models with fast inference |
| `history.csv` | Training history log |
| `model_results.csv` | Model evaluation results |
| `notes.txt` | Supplementary notes |
| `training_curves.png` | Visualization of training/validation curves |
| `training_history.json` | Training history in JSON format |
| `example_log.txt` | Example log file from an ML run |

## 🔑 Key Concepts
- `open()`, `read()`, `write()`, `close()`
- Context managers (`with` statement)
- Reading/writing CSV with `csv` module and `pandas`
- JSON serialization and deserialization
- File paths and `os`/`pathlib` modules
